Before you buy.

What do I need?

Linux and Python 3. Install Tesseract for image OCR; scanned PDFs also need pdftoppm. The optional pypdf package extracts text from regular PDFs.

Does it upload my documents?

The program runs on your computer and listens on loopback. There is no cloud account or remote sync. OCR depends on the optional tools installed locally.

Which files can I add?

PDF, PNG, JPEG, WebP, TIFF and plain text, up to 20 MB per file. Classification is a keyword-based suggestion that you should review.

What does the export contain?

The JSON export includes metadata and extracted text. To keep originals as well, back up the entire PaperWork data folder.
